O projeto consiste em um sistema simples de batalha RPG desenvolvido em Python, utilizando conceitos de classes, objetos, herança e polimorfismo.

🧩 Conceitos de POO utilizados

Classes: Personagem e Monstro

Herança: Guerreiro, Mago e Paladino herdam de Personagem

Polimorfismo: cada personagem possui sua própria implementação do método atacar()

Objetos: personagens e monstros são instanciados para realizar as batalhas

Atributos: hp, mp, speed, atk, matk, defense e mdefense

⚔️ Sistema de Batalha

O projeto possui dois modos:

1v1

Um personagem enfrenta um monstro.

A velocidade (speed) determina quem começa atacando e o dano é calculado utilizando ataque e defesa.

3v3

Uma equipe com 3 personagens enfrenta uma equipe com 3 monstros.

O combate continua até que todos os integrantes de uma das equipes sejam derrotados.
